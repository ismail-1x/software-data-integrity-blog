Software and Data Integrity Failures:

Integrity stays a part of CIA Triad that assure trustworthiness in the cyber world yet its complexity and risk of loosing it keeps evolving. Sometimes From even human mistakes and blind trust in elements for example third party applications or external libraries and dependencies that makes actors trust this code to be correct both now and, in the future, but some cases it wont be.

So what is Software and data integrity?

this term we are going to separate it into 2 parts:

Software integrity: it means the quality of the software’s source code and its essential to measure of how safe secure and reliable it is. We need to measure the maintainability and testability of the code so it’s comfort to the standards. As for concerns to data integrity: the property that data has not been altered, destroyed or lost in unauthorized manner. This assurance must hold true while data is either at rest in transit or actively in use.

But failures occur when some vulnerability left unpatched which allows external attackers to inject malicious updates of compromise the software

Who can be affected?

It compromises emails financial ledgers and reach to employees or customer information, this means businesses lose revenue and operational control.
