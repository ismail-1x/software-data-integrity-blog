Why I Used GitHub Pages

I selected GitHub Pages after comparing it with WordPress.com and Wix. The main reason for my choice was that I wanted to develop the website using HTML and CSS rather than relying mainly on a visual website builder.

Platform Comparison

GitHub Pages allows static HTML, CSS and JavaScript files to be hosted directly from a GitHub repository. It also gives me a version-controlled environment where I can modify the website files and publish updates as the project develops.

  • GitHub Pages — HTML/CSS control and static hosting
  • WordPress.com — blogging platform with additional customization options
  • Wix — visual website builder with customization and development features

Project Purpose
